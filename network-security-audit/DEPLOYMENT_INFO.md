## Security Fixes Deployed

### 🔐 CRITICAL (4 Vulnerabilities Fixed)
1. ✅ **Rate Limiting** - Prevents DoS attacks
   - Port scan: 5 requests/minute
   - Quick audit: 3 requests/minute
   - Read ops: 20-30 requests/minute
   
2. ✅ **API Token Authentication** - Prevents unauthorized access
   - All sensitive endpoints require X-API-Token header
   - 401 Unauthorized if missing/invalid

3. ✅ **Localhost-Only Port Scanning** - Prevents external reconnaissance
   - is_localhost() validation on all targets
   - 403 Forbidden for non-localhost attempts

4. ✅ **Input Validation** - Prevents injection attacks
   - Port range validation (digits, commas, dashes only)
   - Hostname validation (alphanumeric, max 255 chars)
   - Password validation (1-128 characters)
   - SSID validation (max 32 chars per WiFi standard)
