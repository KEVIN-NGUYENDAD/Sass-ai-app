## 🎯 5-Step Deploy (5 mins)

### **Step 1️⃣: Get API Key (1 min)**

Go to: https://console.anthropic.com
1. Click "API keys"
2. Click "Create Key"
3. Copy (starts with `sk-ant-`)
4. Save it!

### **Step 2️⃣: Go to Render (1 min)**

Go to: https://render.com
1. Sign up with GitHub (free account)
2. Click "New +"
3. Click "Web Service"

### **Step 3️⃣: Connect Repository (1 min)**

1. Click "Build and deploy from a Git repository"
2. Click "Connect account" (authorize GitHub)
3. Select: `kevin-nguyendad/huong-pharmacy-ai-copilot`
4. Click "Connect"

### **Step 4️⃣: Configure Service (2 mins)**

```
Service Name:      dual-agents-app
Environment:       Node
Region:            Oregon (or closest)
Branch:            claude/dual-agents-artifact-6ty2wh
Build Command:     npm install
Start Command:     npm start
```

**Scroll down to Environment section:**
```
Add Variable:
  Key:   ANTHROPIC_API_KEY
  Value: sk-ant-your-actual-key-here
```

### **Step 5️⃣: Deploy! (1 min)**

Click: **"Create Web Service"**

Wait 2-3 minutes for deployment...
